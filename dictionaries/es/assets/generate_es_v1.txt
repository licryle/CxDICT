Return a valid JSON array of objects, one per input entry.
Important constraints:
- Output MUST be valid JSON.
- No markdown.
- No extra text, no extra commentary.

- Every input sense must be covered exactly once: no dropped senses, no added senses.

- Preserve multi-sense distinctions when they come from the Chinese source.
